# NEXORA AI — راهنمای اجرا

## قابلیت‌هایی که همین حالا در بخش وب پیاده‌سازی شده‌اند
- جست‌وجو و فیلتر دسته‌بندی ابزارها
- بازکردن لینک ابزارهای معرفی‌شده
- ذخیره و حذف علاقه‌مندی‌ها
- ذخیرهٔ یادداشت، کارها و فلش‌کارت‌ها در مرورگر
- سازندهٔ پرامپت تصویر (متن پرامپت می‌سازد؛ خودش تصویر تولید نمی‌کند)
- خروجی گرفتن و بازیابی پشتیبان JSON
- پوستهٔ روشن/تاریک
- ساختار PWA و ذخیرهٔ فایل‌های اصلی برای استفادهٔ آفلاین بعد از بازدید اول

## انتشار وب
تمام فایل‌های داخل پوشهٔ اصلی را در ریشهٔ مخزن GitHub Pages قرار بده. برنامهٔ پایه در GitHub Pages کار می‌کند، اما API چت به‌تنهایی روی Pages اجرا نمی‌شود.

## فعال‌کردن چت واقعی
پوشهٔ `server` یک سرور Node.js نمونه دارد. برای اجرا:
1. Node.js نسخهٔ 18 یا بالاتر نصب کن.
2. در پوشهٔ `server` دستور `npm install` را اجرا کن.
3. `.env.example` را به `.env` کپی کن و کلید API خودت را فقط در `.env` روی سرور امن قرار بده.
4. دستور `npm start` را اجرا کن.
5. برای استفادهٔ واقعی از سایت منتشرشده، سرور API را روی یک میزبان HTTPS منتشر کن و مسیر `./api/chat` در `app.js` را به نشانی سرور خودت تغییر بده یا از reverse proxy هم‌مبدأ استفاده کن.

**مهم:** کلید API را در `app.js`، HTML یا مخزن عمومی GitHub قرار نده. فایل نمونهٔ سرور نیازمند استقرار و پیکربندی جداگانه است؛ صرف آپلود آن به GitHub Pages چت را فعال نمی‌کند.

## محدودیت‌های شفاف
- ابزارهای بیرونی از طریق لینک رسمی باز می‌شوند و حساب/اشتراک خودشان را ممکن است بخواهند.
- تولید تصویر مستقیم داخل NEXORA هنوز پیاده‌سازی نشده؛ ابزار فضای کار فقط پرامپت می‌سازد.
- PWA برای نصب به HTTPS (مانند GitHub Pages) نیاز دارد.
- قبل از استفادهٔ عمومی، تست روی مرورگر و میزبان نهایی لازم است.
